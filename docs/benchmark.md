# HORMONA - Competitive Benchmark

The academic project reviewed several solutions that help frame the competitive landscape.

| Actor | Approach | Strategic reading for HORMONA |
|---|---|---|
| Level Zero Health | Continuous hormone-monitoring wearable technology | Very close technologically; HORMONA can differentiate through a broader B2C experience and daily guidance. |
| Persperity Health | Non-invasive biosensing, including estradiol monitoring | Similar scientific territory; differentiation depends on UX, target segment and support services. |
| FemSense | Patch + app for fertility based mainly on temperature | Demonstrates acceptance of the patch format; HORMONA aims for more direct biological data. |
| Ava | Fertility wearable using physiological indicators | Indirect alternative showing demand for passive and personalized tracking. |

## Differentiation hypothesis

**Physical sensor + biological data + clear mobile experience + personalized recommendations.**
